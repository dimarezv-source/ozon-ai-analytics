# LILU — подключение бесплатного AI-провайдера

Этот шаг нужен только когда будет готов API-ключ. Само приложение уже поддерживает оба адаптера. Не отправляйте ключ в чат и не вставляйте его в исходный код.

## Вариант 1 — Google Gemini

1. Откройте [Google AI Studio — API keys](https://aistudio.google.com/apikey) и войдите в Google-аккаунт.
2. Проверьте, что AI Studio доступен для страны вашего аккаунта/подключения. Список регионов: [официальная страница Google](https://aistudio.google.com/docs/available-regions).
3. Создайте API key в Google AI Studio. Для выбранных моделей Google указывает бесплатный уровень с бесплатными входными и выходными токенами; переход на платный уровень требует отдельной настройки Cloud Billing.
4. В [Render → LILU → Environment](https://dashboard.render.com/web/srv-dc4m016c6qcc73e3ss1g) добавьте/измените:
   - `AI_PROVIDER` = `gemini`
   - `GEMINI_API_KEY` = ваш ключ
   - `AI_MODEL` = `gemini-3.1-flash-lite-preview`
5. Сохраните изменения. Render перезапустит сервис. Проверьте `/api/health`: должно быть `provider: "gemini"` и `apiConfigured: true`.

**Важно о данных:** Google указывает, что контент бесплатного уровня может использоваться для улучшения продуктов Google. Не отправляйте туда пароли, личные документы, финансовые данные и конфиденциальные переписки.

## Вариант 2 — Groq

Если AI Studio недоступен для вашего региона или аккаунта:

1. Откройте [Groq Console](https://console.groq.com/) и создайте аккаунт/API key.
2. Проверьте доступный бесплатный лимит в [официальной таблице Groq](https://console.groq.com/docs/rate-limits). Лимиты и доступность моделей могут меняться.
3. В Render задайте:
   - `AI_PROVIDER` = `groq`
   - `GROQ_API_KEY` = ваш ключ
   - `AI_MODEL` = `openai/gpt-oss-20b`
4. Сохраните изменения и проверьте `/api/health`.

## Безопасность и расходы

- Не добавляйте карту и не включайте платный тариф, если не хотите оплачивать сервис.
- Не удаляйте существующий `OPENAI_API_KEY`; он остаётся неиспользуемым, пока `AI_PROVIDER` не равен `openai`.
- Приложение не переключает провайдера автоматически и не пересылает одну переписку сразу нескольким провайдерам.
- `apiConfigured: true` означает только, что ключ записан в окружении. Реальный доступ/квота проверяются первым запросом к модели.
- После смены провайдера Render перезапустит сервер; менять код вручную не требуется.
