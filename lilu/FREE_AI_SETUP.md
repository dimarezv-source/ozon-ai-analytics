# LILU — подключение бесплатного AI-провайдера

Адаптеры уже подготовлены в приложении. Для запуска нужен API-ключ выбранного сервиса. Не отправляйте ключ в чат и не вставляйте его в исходный код.

## Вариант 1 — OpenRouter Free Models Router

**Лучший первый кандидат, если важнее всего отсутствие оплаты и карты.** OpenRouter пишет, что начать можно без подписки и карты; для бесплатных моделей не нужно покупать кредиты. Бесплатная квота сейчас — до 50 запросов в день и 20 запросов в минуту.

1. Откройте [OpenRouter — API Keys](https://openrouter.ai/keys) и создайте бесплатный аккаунт и ключ.
2. В [Render → LILU → Environment](https://dashboard.render.com/web/srv-dc4m016c6qcc73e3ss1g) добавьте/измените:
   - `AI_PROVIDER` = `openrouter`
   - `OPENROUTER_API_KEY` = ваш ключ
   - `AI_MODEL` = `openrouter/free`
3. Сохраните изменения. Render перезапустит сервис. Проверьте `/api/health`: должно быть `provider: "openrouter"` и `apiConfigured: true`.

**Ограничения:** бесплатный роутер выбирает доступную бесплатную модель сам. Конкретная модель, скорость, качество и доступность могут меняться. Запросы передаются выбранному upstream-провайдеру модели; учитывайте его правила обработки данных. Не отправляйте личные документы, пароли и конфиденциальные сведения.

Официальные страницы: [Free Models Router](https://openrouter.ai/openrouter/free), [лимиты бесплатных моделей](https://openrouter.ai/collections/free-models/), [начало без карты](https://openrouter.ai/developers).

## Вариант 2 — Google Gemini

1. Откройте [Google AI Studio — API keys](https://aistudio.google.com/apikey) и войдите в Google-аккаунт.
2. Проверьте доступность региона на [официальной странице Google](https://aistudio.google.com/docs/available-regions).
3. Создайте API key. Для отдельных моделей Google указывает бесплатный уровень с бесплатными входными и выходными токенами; переход на платный уровень требует отдельной настройки Cloud Billing.
4. В Render задайте:
   - `AI_PROVIDER` = `gemini`
   - `GEMINI_API_KEY` = ваш ключ
   - `AI_MODEL` = `gemini-3.1-flash-lite-preview`

**Важно о данных:** Google указывает, что контент бесплатного уровня может использоваться для улучшения продуктов Google. Не отправляйте туда конфиденциальные сведения.

## Вариант 3 — Groq

1. Откройте [Groq Console](https://console.groq.com/) и создайте аккаунт/API key.
2. Проверьте доступный бесплатный лимит в [официальной таблице Groq](https://console.groq.com/docs/rate-limits).
3. В Render задайте:
   - `AI_PROVIDER` = `groq`
   - `GROQ_API_KEY` = ваш ключ
   - `AI_MODEL` = `openai/gpt-oss-20b`

## Безопасность и расходы

- Не включайте платный тариф и не покупайте кредиты, если не хотите оплачивать сервис.
- Не удаляйте существующий `OPENAI_API_KEY`; он остаётся неиспользуемым, пока `AI_PROVIDER` не равен `openai`.
- Приложение не переключает провайдера автоматически и не пересылает одну переписку сразу нескольким API.
- `apiConfigured: true` означает только, что ключ записан в окружении. Реальный доступ и квота проверяются первым запросом к модели.
- После смены провайдера Render перезапустит сервер; менять код вручную не требуется.
